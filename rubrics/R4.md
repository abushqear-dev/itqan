# R4 Design critique (UX Spec X-S2; Build; SSI visual polish)

Version: 1. Read rubrics/COMMON.md first.

The existing seven dimensions of `agents/design-critic.md` keep their meaning; this adds anchors. Score each dimension per screen set (desktop and phone).

| Dimension | 5 | 3 | 1 |
|---|---|---|---|
| Hierarchy | One primary action per screen, found first in a 5-second look | The primary action is findable but competes with one other element | No clear primary action, or the eye lands on decoration |
| Typography | ≤ 6 sizes on a clear scale; measure and line height comfortable; headings balanced | A clear scale with one or two off-scale sizes or a cramped measure | Many unrelated sizes; long lines; weak contrast between levels |
| Colour | Palette in its intended proportions; accent only for action and state; contrast holds | The accent is used decoratively in places; one weak contrast pair | No palette logic; accent everywhere; contrast failures |
| Spacing and layout | Token rhythm everywhere; clear grouping; grid alignment; the phone layout is designed, not shrunk | Mostly consistent with a few off-token gaps; the phone layout is just stacked | Arbitrary gaps; misalignment; the phone layout breaks |
| Consistency | The same component is identical on every screen; one icon set; one button shape | One or two component variants drift | Components differ screen to screen |
| Fit and character | Feels made for this product and its users, per the visual direction | Competent but generic, with recognisable template tells | Template look, or contradicts the direction |
| Polish | Every state designed; copy names actions; focus rings, selection and numerals themed; nothing clipped | Most states present; a few generic labels or an unthemed focus | Missing states; clipped or overlapping elements; raw browser defaults |

Pass rule unchanged: every dimension ≥ 4.
