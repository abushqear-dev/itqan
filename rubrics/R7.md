# R7 Pairwise against a competitor (UX Spec X-S7; SSI visual polish)

Version: 1. Read rubrics/COMMON.md first.

Inputs are two screenshots of the same job (ours and a competitor's) at the same viewport with similar data, logos and names removed, labelled A and B at random. Each pair is run in both orders.

Question: "A user who must do <job> every day: which screen would they rather use, and which looks more trustworthy and professional?"

| Answer | Meaning |
|---|---|
| A / B | Clear preference, with three pieces of visible evidence |
| Tie | No clear preference, or the evidence is split |

If the verdict changes with the order, the result is a tie. The metric is the win-or-tie rate over all pairs. The flip rate is reported with it. When available, UIClip's pairwise score is reported beside the judge's as a second opinion, not averaged with it.
