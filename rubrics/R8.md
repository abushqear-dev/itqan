# R8 Test quality (Build, B-S8)

Version: 1. Read rubrics/COMMON.md first.

Per test file in the task:

| Level | Anchor |
|---|---|
| 5 | Each test asserts observable behaviour from its criterion's Example. It would fail if the behaviour broke. Mocks only at system edges (network, clock). |
| 3 | Mostly behavioural, with one test coupled to implementation details or one over-mocked collaborator. |
| 1 | Tautological (asserts what it set up), checks only that a mock was called, or would pass with the feature removed. |

Mutation score (B-S2) is the script-side check of the same property. A file with a high R8 level but low mutation score is flagged for review.
