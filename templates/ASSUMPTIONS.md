# Assumptions

Every assumption the agent makes, with the stage that made it. Reviewed at each approval.

| ID | Stage | Assumption | Why | Status |
|----|-------|------------|-----|--------|

Status: `open` (not yet answered), `accepted` (the document containing it was approved without the user answering it individually), `confirmed` (the user explicitly agreed), `replaced` (the user decided otherwise). Approving a document never makes an assumption `confirmed`.
